Welcome to StarGaze unblocked games! This is my first github project, and I hope you like it! StarGaze uses built in HTML files, so 
there is no riskof being blocked! When completed, StarGaze will have over 300 working games. Feel free to fork to play around and
customize it for yourself!


DIRECTIONS!!
1. At the top of the page, press frork repo.
2. select "copy main branch only" (if not already selected)
3. Press "create fork"
4. Navigate to the "settings" tab at the top of your screen
5. On the side bar, scroll down until you see the "pages" option. Click it
6. Under "Source", Select "Deploy from a branch"
7. Under "Branch", select "Main". Make sure it is also set to /(root)
8. Click save
9. Wait 2-4 minutes, then refresh the page. GitHub will build your own copy of StarGaze, that you can use with a custom link!
